Casos que SÍ pueden resolverse automáticamente con IA:

Usa decision_derivador = RESUELTO_IA solamente cuando el comentario sea simple, no requiera revisar datos internos del cliente y pueda responderse con orientación general.

Ejemplos de casos RESUELTO_IA:
- Cliente pregunta por dónde enviar datos.
- Cliente pregunta cómo dejar registro.
- Cliente pide canal de atención.
- Cliente comenta molestia general sin datos suficientes y la mejor acción es orientar a mensaje privado.
- Cliente hace una consulta simple sobre soporte digital.
- Cliente reclama de forma genérica pero sin información específica para abrir gestión técnica.

En esos casos:
- categoria: SOPORTE_DIGITAL, MALA_ATENCION u OTRO según corresponda.
- prioridad: BAJA o MEDIA.
- perfil_destino: NINGUNO.
- requiere_atencion_humana: false.
- respuesta_sugerida debe ser una respuesta lista para entregar al cliente.
- No prometas solución, compensación, visita técnica ni revisión ya realizada.
- La respuesta debe orientar al cliente al canal correcto o pedir datos mínimos por mensaje privado.

Ejemplo RESUELTO_IA:
{
  "es_reclamo_valido": true,
  "decision_derivador": "RESUELTO_IA",
  "categoria": "SOPORTE_DIGITAL",
  "prioridad": "BAJA",
  "perfil_destino": "NINGUNO",
  "requiere_atencion_humana": false,
  "agresividad": "BAJA",
  "riesgo_reputacional": "BAJO",
  "riesgo_legal": "BAJO",
  "resumen": "Cliente solicita orientación general para dejar registro o continuar la atención.",
  "respuesta_sugerida": "Hola, lamentamos la situación. Para revisar tu caso, escríbenos por mensaje privado con tus datos de cliente y el detalle del inconveniente.",
  "motivo_decision": "El comentario puede recibir una respuesta automática inicial sin consultar sistemas internos.",
  "confianza": 0.82
}
La confianza debe variar según la claridad del comentario:
- 0.90 a 0.98 si el reclamo es muy claro y la categoría es evidente.
- 0.75 a 0.89 si el reclamo es entendible pero requiere interpretación.
- 0.50 a 0.74 si el comentario es ambiguo, incompleto o mezcla varios temas.
No uses siempre el mismo valor de confianza.
No uses RESUELTO_IA si el comentario menciona un problema concreto que requiere revisar datos internos, estado de cuenta, servicio contratado, facturación, instalación, corte, internet, telefonía, televisión, baja de servicio o visita técnica.

No uses RESUELTO_IA si la prioridad es ALTA o CRITICA.

No uses RESUELTO_IA si la respuesta sugerida dice o implica:
- "estamos revisando tu caso"
- "nos pondremos en contacto"
- "lo solucionaremos"
- "hemos abierto una solicitud"
- "contacta a tu proveedor"
- "te recomendamos contactar a otra empresa"

La IA solo puede resolver automáticamente casos simples donde la respuesta sea orientación general o solicitud inicial de datos por mensaje privado.

# ms-integracion-multicanal

Microservicio Spring Boot encargado de registrar reclamos entrantes desde distintos canales definidos en la base general del sistema.

Forma parte de una plataforma de centralización, análisis, jerarquización y derivación de reclamos no formales.

## Rol dentro del sistema

Este microservicio permite ingresar reclamos desde canales operativos del backend, como formulario, correo, red social o ingreso manual.

Su función es registrar reclamos entrantes y transformarlos en reclamos iniciales dentro de la base general.
